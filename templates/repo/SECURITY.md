# Security policy

## Reporting a vulnerability

Please report security problems privately, through GitHub's private vulnerability reporting on this repository (the
Security tab, then "Report a vulnerability"), never in a public issue. Do not include passwords, tokens, keys or
personal data in a report. The maintainers acknowledge a report as soon as they can and agree on a fix and its
disclosure with the reporter.

## Supported versions

Only the current `main` branch is deployed, and only it receives fixes.
