# 1.31.11: why a stage is there, on request

Asked after 1.31.10: the "Why it is here" and "If it fails" lines under every stage made the page busy, and should open on
request instead of always showing.

Both lines now sit in one closed section, "Why it is here · If it fails", in the card for the stage happening now and
under every stage of the journey, beside that stage's GitHub steps. Each section has its own id, so one that is opened
stays open when the page refreshes every 10 seconds. A stopped release still shows what to do now without a click.
